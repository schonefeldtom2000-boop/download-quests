# QUESTS — GitHub Pages

Upload `index.html`, `quests.apk`, and this README to the root of a GitHub repository.

Then:
1. Repository → Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main`, folder: `/ (root)`
4. Save and wait for deployment.

The page includes an orange theme, APK download button, and an installation tutorial modal.
Only publish the APK if you have permission to distribute it.
